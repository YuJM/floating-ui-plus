---
title: Web Components
description: Compose accessible floating surfaces with native Custom Elements.
---

Register the elements once:

```ts
import '@floating-ui-plus/web-components';
```

Use a root-owned template for a conditional anchored surface:

```html
<floating-root interactions="click dismiss" floating-role="dialog">
  <floating-reference><button>Open settings</button></floating-reference>
  <template slot="content">
    <section aria-label="Settings">
      Settings
      <button data-fup-close>Close</button>
    </section>
  </template>
</floating-root>
```

For a modal, use `<dialog slot="floating">`. Listen for
`floatingbeforeclose` when a close needs synchronous validation, and call
`root.close()` for an imperative close.
