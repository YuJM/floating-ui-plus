---
title: Vue
description: Compose Floating UI Plus surfaces with Vue composables and components.
---

Use `useFloating()` when your component owns markup, or `FloatingRoot` and
`FloatingContent` for declarative composition:

```vue
<FloatingRoot
  v-model:open="open"
  :options="{onBeforeClose: (_event, reason) => canClose(reason)}"
>
  <FloatingReference>Open settings</FloatingReference>
  <FloatingContent>
    Settings
    <FloatingClose>Close</FloatingClose>
  </FloatingContent>
</FloatingRoot>
```

Use `<FloatingContent as="dialog">` for a native modal. Keep the surface in
the Vue tree for native top-layer mode; add `FloatingPortal` only when a
body-level Teleport is explicitly required.
