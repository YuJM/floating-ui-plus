Floating UI Plus adds interaction, focus, collection, search, and native
top-layer behavior to Floating UI positioning primitives. Choose the adapter
that matches your renderer and keep the same behavior contract across them.

## Start here

- [Getting started](/docs/guides/getting-started): choose a package and wire your first surface.
- [Usage recipes](/docs/guides/usage): complete adapter examples for surfaces, portals, collections, and search.
- [Demo walkthrough](/docs/guides/demo): every interactive example, route, and middleware comparison.
- [Popover and dialog](/docs/guides/popover): use native Popover, `<dialog>`, templates, and portals deliberately.
- [Combobox](/docs/guides/combobox): connect fuzzy or server search to editable input behavior.
- [Dismiss and closing](/docs/guides/dismiss): distinguish `close()` from `dismiss()` and guard close requests.

## Choose an adapter

- [Web](/docs/frameworks/web): framework-neutral controllers and render contracts.
- [Web Components and Vue](/docs/frameworks): adapter-specific markup with a shared API contract.

The [API Reference](/docs/api/readme) is generated from the published TypeScript
entry points. The [live demo](/) shows the same patterns running in the
browser, including the [combobox](/combobox?source=fuzzy) and [modal](/modal)
examples.
