Floating UI Plus adds interaction, focus, collection, search, and native
top-layer behavior to Floating UI positioning primitives. Choose the adapter
that matches your renderer and keep the same behavior contract across them.

## Install one adapter

Install the package that matches the renderer you use. The Web Components and
Vue adapters install `@floating-ui-plus/web` as a transitive dependency, so you
do not need to install the Web package separately when using either adapter.

- [Install Web Components](/docs/guides/installation/web-components): Custom Elements with no framework runtime.
- [Install Vue](/docs/guides/installation/vue): Vue 3 components and composables.
- [Install the Web core](/docs/guides/installation/web): framework-neutral controllers and render contracts.
