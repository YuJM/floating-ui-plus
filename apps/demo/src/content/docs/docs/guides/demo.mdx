The demo is an executable companion to the documentation. Each example has a
dedicated guide with the behavior it demonstrates, the important API choices,
and a direct link to the live route.

All routes accept `framework=wc` (Web Components, the default) or
`framework=vue`.
The previous `framework=web-components` value is still read as Web Components
for bookmarked links, but new links use the shorter `wc` token.
The combobox route also accepts `source=fuzzy` or `source=server`.

## Reusing an example

Install `@floating-ui-plus/web-components` for a Web Components example or
`@floating-ui-plus/vue` for a Vue example. Each adapter resolves
`@floating-ui-plus/web` through its own package dependency; the example code
imports Floating UI Plus APIs only from its selected adapter. Vue itself is
the Vue adapter's peer dependency.

The source tabs show components from this demo application. Data, labels,
styles, and the simulated server belong to the application rather than the
adapter packages. If an example imports one of those files, copy the relevant
application code or replace it with your own. The
[fuzzy Query](/docs/guides/demo/combobox/fuzzy) and
[server Query](/docs/guides/demo/combobox/server) guides show their supporting
search code. The release check also builds the public imports used by every
example from packed adapter packages in independent consumer projects.

## Interaction demos

- [Tooltip](/docs/guides/demo/tooltip): hover, focus, safe polygon, and arrow.
- [Popover](/docs/guides/demo/popover): root-owned template and native Popover.
- [Menu](/docs/guides/demo/menu): list navigation, typeahead, and looping.
- [Nested menu](/docs/guides/demo/nested-menu): coordinated roots and focus restoration.
- [Client point](/docs/guides/demo/client-point): cursor-following virtual reference.
- [Combobox: fuzzy search](/docs/guides/demo/combobox/fuzzy): local typo-tolerant matching.
- [Combobox: server search](/docs/guides/demo/combobox/server): cancellable cursor-based requests.
- [Placement](/docs/guides/demo/placement): all typed placement values.
- [Middleware](/docs/guides/demo/middleware): eight positioning middleware comparisons.
- [Modal](/docs/guides/demo/modal): native dialog, nested surfaces, and focus traps.
- [Sheet](/docs/guides/demo/sheet): four edge positions, backdrop dismissal, and exit animation.
- [Toast](/docs/guides/demo/toast): stacked notifications, opt-in hover/focus pause, a hit box sized to the current stack, readable paused row spacing, F6 navigation, and exit presence.
- [Command](/docs/guides/demo/command): searchable grouped actions in a keyboard-operable dialog palette.

The [Usage recipes](/docs/guides/usage) page covers reusable compositions;
these pages explain what each demo is doing differently.
