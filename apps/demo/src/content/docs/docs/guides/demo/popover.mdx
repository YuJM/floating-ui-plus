The trigger and panel remain in one root. The template is inert while closed
and becomes a native Popover when opened:

```html
<floating-root
  interactions="click dismiss"
  floating-role="dialog"
  placement="bottom-start"
>
  <floating-reference><button>Open coordinates</button></floating-reference>
  <template slot="content">
    <section aria-label="Coordinates">
      Popover, still connected.
      <button data-fup-close>Close panel</button>
    </section>
  </template>
</floating-root>
```

The demo uses `offset(12)`, `flip()`, and `shift({padding: 18})`. The Vue
version uses `FloatingRoot`, `FloatingReference`, and `FloatingContent` without
changing the interaction model. Use a portal only when the panel must escape a
clipping ancestor; it is not required for this composition.
