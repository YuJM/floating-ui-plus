---
title: LLM documentation
description: Use the generated llms.txt index to give coding agents a concise map of Floating UI Plus documentation.
---

The demo site publishes [`/llms.txt`](/llms.txt) for coding agents and other
documentation-aware tools. It follows the same useful shape as the Base UI
index: a short project description, package links, and grouped documentation
links.

The file is generated from the Markdown/MDX frontmatter during every demo
`dev`, `typecheck`, and `build` command. The generator uses
[`@comneed/textby`](https://github.com/comneed/abiy/tree/main/packages/textby)
with an inline Liquid template, so adding a guide only requires adding its
normal `title` and `description` frontmatter.

```bash
bun run --filter floating-ui-plus-demo generate:llms
```

The generated output is written to `apps/demo/public/llms.txt`, which Astro
serves as a static root asset. The source of truth is the documentation tree;
do not edit `llms.txt` by hand. Set `PUBLIC_SITE_URL` when building a preview
or deployment with a different canonical host so generated links point to the
right site.

The index intentionally links to the human-readable HTML documentation. An
agent can start at `/llms.txt`, select the relevant guide, and then follow the
normal Starlight page. Package API details remain in the generated TypeDoc and
package READMEs rather than being duplicated in the index.
